A one-image newspaper front page summing up the world news of Thursday
26 November 2026, built for make.fun's
[news-image-20261126](https://make.fun/bounty/news-image-20261126) competition.

The lead story is Washington's proposal for new tariffs on 14 trading partners.
Around it sit six short panels — Middle East energy fears, a fatal tanker fire
near Cairo, EU leaders split over Ukraine financing, DR Congo's Ebola outbreak
passing 12,000 cases, the first Pakistani astronaut aboard China's Tiangong
station, and Bangladesh's garment wage rise — plus a North Korea brief.
Claims that were not independently confirmed at publication time are shown as
attributed claims.

## Run

```sh
python3 main.py
```

This writes `entry.png` (1024×1024 PNG) to the current directory, or to
`$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set. The program uses
only fixed text and geometry with Pillow and DejaVu fonts, so repeated runs
produce byte-identical output.
